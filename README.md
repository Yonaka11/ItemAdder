# Square Catalog Sandbox Tool

Kotlin-based Android sandbox project for exploring Square catalog item creation, product data modeling, and API-driven business workflows.

## Overview

Square Catalog Sandbox Tool is a portfolio project built to explore how product and catalog data can be structured, validated, and submitted through Square's API ecosystem.

While Square provides official dashboard tools for managing item libraries, this project focuses on the developer side: API request handling, catalog object structure, sandbox testing, validation errors, and business workflow automation concepts.

## Features

* Create or update Square catalog items in a sandbox environment
* Work with item options, variations, and structured product data
* Handle API validation errors and response messages
* Explore catalog automation workflows
* Test business tooling concepts without affecting live production data

## Tech Stack

* Kotlin
* Android
* Ktor / OkHttp
* Square Sandbox API
* JSON
* REST APIs

## What This Demonstrates

* Business systems thinking
* API request and response handling
* Catalog and product data modeling
* Error handling and root-cause debugging
* Understanding of sandbox vs. production environments
* Mobile tooling concepts for small-business workflows

## Status

Sandbox portfolio project. This is not intended to replace Square's official dashboard tools. It was built to demonstrate API integration, catalog workflow logic, and business systems development.
