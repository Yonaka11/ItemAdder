# Square Inventory Companion

Kotlin-based Android sandbox project for exploring retail inventory lookup, price checking, and Square catalog workflows.

## Overview

Square Inventory Companion is a sandbox portfolio project built to explore how a small business could scan, search, and review product information before updating or syncing catalog data through Square's API ecosystem.

Square already provides official tools for item libraries, inventory tracking, and point-of-sale workflows. This project focuses on the developer and operations side: inventory lookup, price checking, product data modeling, API request handling, sandbox testing, and business workflow automation concepts.

## Features

* Search or scan items for quick price and inventory review
* Explore Square catalog item structures in a sandbox environment
* Work with item options, variations, SKUs, and structured product data
* Review product details before catalog updates
* Handle API validation errors and response messages
* Test business tooling concepts without affecting live production data

## Tech Stack

* Kotlin
* Android
* Ktor / OkHttp
* Square Sandbox API
* JSON
* REST APIs

## What This Demonstrates

* Business systems thinking
* Retail inventory workflow design
* API request and response handling
* Catalog and product data modeling
* Error handling and root-cause debugging
* Understanding of sandbox vs. production environments
* Mobile tooling concepts for small-business operations

## Status

Sandbox portfolio project. This is not intended to replace Square's official dashboard or retail tools. It was built to demonstrate API integration, inventory workflow logic, price-checking concepts, and business systems development.
